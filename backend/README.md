# Backend

Backend services for SurakshaAR: REST API, data models, services, authentication, and database access.

> **Status:** Scaffolding only. No code implemented yet; `requirements.txt` is intentionally empty until
> dependencies are chosen.

## Structure

| Path | Purpose |
|---|---|
| `app/api/` | API routes / controllers |
| `app/models/` | Data models / ORM models |
| `app/services/` | Business logic and service layer |
| `app/auth/` | Authentication and authorization logic |
| `app/database/` | Database connection and migrations |
| `tests/` | Backend tests |
| `requirements.txt` | Python dependencies (to be populated) |

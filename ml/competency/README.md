# ML — Competency

Machine-learning components that score worker competency during and after assessment scenarios, and that
detect performance weaknesses to drive targeted retraining.

> **Status:** Scaffolding only. No models or code implemented yet.

## Structure

| Path | Purpose |
|---|---|
| `scoring/` | Competency scoring models and logic |
| `weakness_detection/` | Detection of skill/performance weaknesses |
| `retraining/` | Retraining scheduling/curriculum logic driven by weaknesses |
| `sample_data/` | Sample datasets for development and testing |
| `tests/` | Tests for scoring, detection, and retraining |

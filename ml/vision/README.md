# ML — Vision

Computer-vision models and inference for recognizing worker actions, safety-equipment usage, and hazardous
conditions within AR scenarios.

> **Status:** Scaffolding only. No models or code implemented yet.

## Structure

| Path | Purpose |
|---|---|
| `models/` | Vision model definitions and weights |
| `inference/` | Inference pipelines and wrappers |
| `preprocessing/` | Input preprocessing (frames, augmentation, normalization) |
| `sample_data/` | Sample image/video data for development and tests |
| `tests/` | Tests for preprocessing, models, and inference |

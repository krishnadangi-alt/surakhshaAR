# Security

Security framework for the SurakshaAR platform: threat modeling, authentication, authorization, API
security, data protection, and security testing.

> **Status:** Scaffolding only. No code implemented yet.

## Structure

| Path | Purpose |
|---|---|
| `threat-model/` | Threat model and risk assessments |
| `authentication/` | Authentication design & implementation |
| `authorization/` | Authorization / access-control design & implementation |
| `api-security/` | API security controls (input validation, rate limiting, etc.) |
| `data-protection/` | Data protection, privacy, and encryption guidance |
| `security-tests/` | Security test plans and tooling |

# Certificate

SurakshaAR training.

> **Status:** Scaffolding only. No code implemented yet.

| Path | Purpose |
|---|---|
| `generation/` | Certificate creation (rendering, templating) |
| `verification/` | Certificate authenticity verification |
| `qr/` | QR code generation and scanning |
| `templates/` | Certificate layout templates |
| `tests/` | Certificate pipeline tests |

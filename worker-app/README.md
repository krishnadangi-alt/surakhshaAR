# Worker App (Unity)

The Unity-based AR worker application for SurakshaAR. Contains the immersive training and assessment
experiences for fire and gas safety scenarios.

> **Status:** Scaffolding only. No scenes, scripts, or Unity configuration files have been added yet.

## Structure

| Path | Purpose |
|---|---|
| `Assets/Scenes/MainMenu/` | Main menu scene(s) |
| `Assets/Scenes/Training/` | Training mode scenes |
| `Assets/Scenes/Assessment/` | Assessment mode scenes |
| `Assets/Scenes/Fire/` | Fire-safety scenario scenes |
| `Assets/Scenes/Gas/` | Gas-safety scenario scenes |
| `Assets/Scripts/Core/` | Core application scripts |
| `Assets/Scripts/AR/` | AR-specific scripts (tracking, placement, gestures) |
| `Assets/Scripts/Training/` | Training mode logic and interactions |
| `Assets/Scripts/Assessment/` | Assessment mode logic and scoring hooks |
| `Assets/Scripts/Localization/` | Localization / multi-language support |
| `Assets/Scripts/Networking/` | API and networking clients |
| `Assets/Prefabs/AR/` | Reusable AR prefabs |
| `Assets/Prefabs/Fire/` | Fire-scenario prefabs |
| `Assets/Prefabs/Gas/` | Gas-scenario prefabs |
| `Assets/Materials/` | Materials |
| `Assets/Models/` | 3D models |
| `Assets/Textures/` | Textures |
| `Assets/Audio/` | Audio clips |
| `Assets/UI/` | UI assets / screens |
| `Assets/Resources/` | Runtime-loadable resources |
| `Packages/` | Unity package manifest and dependencies |
| `ProjectSettings/` | Unity project settings |

## Notes

- This is a standard Unity project layout. `Packages/manifest.json` and `ProjectSettings/ProjectVersion.txt`
  are generated by the Unity Editor on first open and are intentionally not committed at scaffold time.
- Empty directories are kept in version control with zero-byte `.gitkeep` files so the intended layout
  is preserved.
